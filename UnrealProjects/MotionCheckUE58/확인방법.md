# MotionCheckUE58 · Unreal5.8 화면 확인

프로젝트: MotionCheckUE58.uproject

1. Unreal5.8로 프로젝트를 연다.
2. Content Drawer(Ctrl+Space) → MotionPreview → ReferenceMotion_Anim을 더블클릭한다.
3. 아래 재생 버튼을 누른다. 30fps /447키 /약14.87초다.
4. 원근 메뉴 → 따라가기 모드 → 루트 공전을 선택하면 이동하는 몸을 화면 중앙에서 볼 수 있다.

레벨 Preview에서는 Outliner의 Motion Reference를 선택하고 F로 화면을 맞춘다. 기본 레벨 조명 재빌드 경고와 시작 카메라 초기값은 아직 남아 있다. 애니메이션 에디터의 환경 조명에서는 리그가 보이며 실제 재생을 확인했다.

기준 BoneProxy용이며 제작용 캐릭터에 리타깃한 결과는 아니다. 원본 추론과 .blend는 보존했다.
