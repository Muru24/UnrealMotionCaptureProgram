Motion Studio — 디자인 목업 안내

이 페이지는 현재 UnrealMotionCaptureProgram 프로젝트의 화면 개편안입니다. 설치나 로그인 없이 HTML 파일을 열어 사용할 수 있습니다.

  • 왼쪽 4단계를 클릭해 실제 프로그램과 비슷한 작업 흐름을 확인하세요.
  • 영상 파일을 끌어놓으면 브라우저가 그 영상만 로컬에서 재생합니다.
  • 트래킹 진행 버튼은 시뮬레이션이며 모델 분석이나 파일 저장은 수행하지 않습니다.
  • 본 검수의 시점 버튼, 타임라인 키 추가, UI 토글 등을 눌러 볼 수 있습니다.
  • 실제 앱으로 적용할 때는 기존 Tkinter 위젯 구현이나 별도의 웹뷰 기술로 화면을 옮겨야 합니다.
