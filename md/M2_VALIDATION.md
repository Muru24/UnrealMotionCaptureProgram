## 고정 입력과 실행

입력 위치는 `C:\Users\user1\Videos`. 원본 SHA256·해상도·FPS·실제 디코딩 수는 `validation/m2/v1/sources.json`, 현재 코드 해시·가중치 manifest·실행 설정·결과 해시는 `baseline.json`에 보존한다.

공통 실행: `.venv\Scripts\python.exe -m app.cli "C:\Users\user1\Videos\<이름>.mp4" --pose3d --max-people 4 --target-index 0 --output "outputs\M2_reference_v1_<이름>" --json`

Sword는 거울에 비친 사람이 있으므로 single-person 가정을 사용하지 않는다. 다른 모델은 index 0의 순서를 그대로 믿지 않고 첫 프레임의 실제 동일 인물을 선택했는지 확인한다. 첫 프레임 기준 이미지는 evidence의 first.png이며, 출력 첫 프레임과 대조한다. 대상 선택이 다르면 해당 실행은 비교에서 제외하고 새 출력에 재실행한다.

프레임은 0부터 시작하고 구간 끝은 포함하지 않는다. 시간은 frame/FPS이며 컨테이너의 가변 PTS와 다를 수 있다. metadata 프레임 수로 누락 판정하지 않고 전체 디코딩 수와 출력 정렬을 확인한다.

## 판정 절차

1. 전체 입력과 출력의 프레임·시간·JSON 33관절 정렬, null/invalid, 유한 좌표, 출력 영상 전체 디코딩을 확인한다.
2. 전체 overlay를 원본과 대조해 대상 교체·거울 선택·회전 분실을 확인한다. 의심 구간은 프레임별로 본다. track_id 유지 자체는 동일 인물 증거가 아니다.
3. 고정 구간 전체를 정상 속도와 프레임 단위로 확인한다. 관절은 좌우 어깨/팔꿈치/손목/골반/무릎/발목 12개를 우선 평가한다. 각 프레임·관절을 visible / occluded / out_of_frame / ambiguous로 구분한다. 소매 안 실제 관절을 임의로 정답 좌표로 만들지 않는다.
4. visible인 관절만 수동 기준점과 오차를 비교한다. 기준점은 모델 결과를 가린 원본에서 먼저 작성한다. 몸통 길이 L은 수동 어깨 중점–골반 중점 거리, 허용오차는 max(8px, 0.15L), 기준점 불확실성은 최대 max(4px, 0.05L)로 기록한다. 이를 넘게 불명확하면 ambiguous로 분리한다. 이 수치는 본 프로젝트의 잠정 공학 기준이며 실측 3D 정확도 표준이 아니다.
5. 프레임/관절별 기준점·가시성·예측 valid·거리·판정·사유를 남긴 뒤 분모를 공개한다. 수동 기준점 작성 전에는 정확도 %를 보고하지 않는다. occluded/out_of_frame 비율도 공개하고, 이를 늘려 성능이 오른 것으로 판단하지 않는다.

## M2 통과 조건

아래는 모두 충족해야 한다. 현재 미측정 항목은 PASS가 아닌 NOT_EVALUATED다.

| 항목 | 기준 |
|---|---|
| 데이터 무결성 | 원본 실제 디코딩 수 = 모든 JSON 프레임 수 = 두 출력 영상 디코딩 수. 좌표/누락/축·단위 메타데이터 일치 |
| 대상 일관성 | 전체 영상에서 잘못된 인물/거울/장식품으로 대상 교체 0건 |
| 관측 가능 구간 추적 | 각 고정 구간에서 몸통이 확인 가능한 프레임의 tracked 비율 ≥95%, 연속 분실 >0.2초 0건 |
| 관절 위치 | visible 기준점 중 valid이면서 허용오차 이내 ≥95%를 영상별·구간별 모두 충족. invalid도 이 분모에 포함해 누락으로 실패 처리 |
| 지속 오추정 | 고정 구간에서 visible 팔/다리가 머리카락·옷·장식품 등 잘못된 위치에 붙는 오류가 연속 ≥0.1초이면 실패. 단발 오류도 위 위치 점수에 포함 |
| 연속 누락 | visible 필수 관절 연속 누락 >0.2초 0건. 가려진 관절의 invalid는 정직한 결측으로 기록하되 visible 복귀 후 동일 기준 적용 |
| 알려진 오류 | M2-005 Norma 분실, M2-006 팔 누락/머리카락 오추정 재현 구간의 개선을 증거로 확인. 전체 평균으로 실패 구간을 상쇄하지 않음 |
| 3D 점검 | 원시 world/투영 관계, 좌우·깊이 급반전·비정상 붕괴를 연속 preview로 검토. 실측 GT가 없으므로 미터 오차나 진짜 깊이 정확도를 인증하지 않음 |
| 회귀 | 기존 M0/M1/GUI/다중 후보 보호/취소/오프라인/관련 자동 테스트 유지. 단일 사람 4개 영상만으로 실제 다중인 교차 검증 완료를 선언하지 않음 |

confidence/visibility/presence, valid_joint_ratio, frames_with_target는 정확도 점수가 아니다. warning 출력, 모든 관절 invalid, 화면에서 선 숨김, smoothing만으로 위 오류를 해결한 것으로 간주하지 않는다.
실측 불가능한 가림 구간의 실제 포즈 복원을 M2에서 보증하지 않는다. M3/M4 제약, M8 떨림/짧은 결측, M9 수동 편집은 남지만 현재 visible 지속 오추정의 통과 면제 사유가 아니다.

## 재현과 판정 기록

현재 전체 실행 결과/리뷰는 `validation/m2/v1/baseline.json`, `review.md`를 함께 읽는다. `summarize.py`는 저장된 결과에서 해시·정렬·영상 디코딩을 확인하고 비교 이미지를 다시 만든다. 프로젝트 루트에서 `.venv\Scripts\python.exe validation\m2\v1\summarize.py`로 실행한다. 원본/기존 출력은 덮어쓰지 않는다.

현재는 알려진 실패를 고정한 기준선이며 수동 좌표 전수 라벨은 작성 전이다. 따라서 4개 전체의 관절 정확도/최종 통과 판정은 미완료다. 모델 비교 때 동일 가시성 라벨과 기준점을 재사용한다. 결과를 본 뒤 기준을 낮추거나 실패 구간을 빼지 않는다. 입력/구간/기준이 변경되면 v2로 분리한다.
